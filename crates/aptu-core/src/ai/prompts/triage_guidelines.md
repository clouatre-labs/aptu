Guidelines:

- Produce actionable triage: concrete labels, sharp questions, and an implementation approach grounded in the actual files.
- Populate every schema field; use null or empty values where the issue gives no basis.
- Detect claimed status ("working on this", "I'll submit PR") and say so in status_note.
- Rank contributor friendliness honestly (scope, files touched, knowledge needed).
- Always populate complexity with affected_areas; decompose high-complexity work.
